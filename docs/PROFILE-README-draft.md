### Aurelia Antlers — jewellery digital twins & virtual try-on
[`Aditya17-bot/jewel`](https://github.com/Aditya17-bot/jewel)

A jeweller's catalogue you can turn, and a customer trying it on through their own camera. No server, no API keys, no GPU — MediaPipe's 468 facial landmarks in-browser mean the person is solved geometry, so the whole problem reduces to materials and light. Every asset is baked offline from the same three.js scene the live viewer uses, so a spinner can never drift from the product.

`React 19 · three.js · MediaPipe · Canvas 2D · Python`
